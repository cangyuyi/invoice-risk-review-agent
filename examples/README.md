# 示例结果说明

`audit_results.json` 是**结构化规则层**的命令行演示结果，只验证 R00、R01、R10、R11、R20 和 R30。

其中出现 1 条 `auto_pass`，含义仅是“没有命中当前结构化重复规则”，不代表发票已经验真，也不代表真实报销可以自动通过。

真实图片端到端演示会在规则层之后检查税务权威状态。由于当前未接入验真、红冲和作废查询，原规则层的 `auto_pass` 会被 R40 改为 `manual_review`，因此端到端报告的自动放行数为 0。

- `../eval/README.md`：36 条结构化规则回归；
- `../eval/end_to_end_demo_report.md`：图片到风险结论的完整说明。
