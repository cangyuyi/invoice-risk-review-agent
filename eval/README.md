## 正确解读

本评测全部使用合成结构化数据，验证的是：

1. 固定输入下，确定性规则能否稳定输出预期决策；
2. 批次重复、历史重复、疑似重复和异常输入是否走向正确的人工复核路径；
3. 规则修改后能否使用同一黄金集进行回归。

它不代表：

- OCR 字段准确率为 100%；
- 真实企业重复报销拦截率为 100%；
- 假票、红冲或作废识别准确率为 100%；
- 系统可以替代财务人员最终审核。
