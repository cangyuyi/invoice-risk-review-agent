# 图片到风险结论：端到端演示

## 流程

```text
5 张本地票据图片
→ 二维码解析票号、日期、金额
→ 合并脱敏演示元数据
→ 批次文件哈希 / 票号查重
→ 合成历史台账比对
→ 风险等级、规则、证据与人工动作
```

## 结果

| 结果 | 数量 | 规则与原因 |
| --- | ---: | --- |
| 高风险确认重复 | 2 | R10 同图哈希 + R11 同票号 |
| 中风险疑似重复 | 2 | R30 同销售方、同金额、日期相邻 |
| 状态未验真 | 1 | R40 未查询税务有效、红冲和作废状态 |
| 自动通过 | 0 | 缺少税务权威状态，不自动放行 |

公开结果只含匿名记录号、风险结论、规则和证据。二维码原文、真实票号及逐字段结果保存在本地私有目录。

## 证据边界

图片与二维码字段来自 5 张本地测试图片；销售方等补充字段和历史台账是脱敏/合成演示数据。R20 历史票号精确重复已在 36 条合成规则回归中验证，但本次真实图片链路未验证 R20 命中。二维码成功也不等于发票真实有效。

## 产品价值

演示重点不是“模型自动审批”，而是把每个结论拆成可复现规则、可查看证据和明确兜底动作。识别层失败或权威状态缺失时，系统降级到人工复核，而不是编造确定答案。
